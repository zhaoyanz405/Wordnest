# Wordnest · 拾词 Chrome 单词本

保留已确认的 Animal Island UI 风格，从界面原型推进到可加载的 Manifest V3 插件。

## 安装第一版

在本目录中先安装依赖并构建：

```sh
npm ci
npm run build:extension
```

构建生成的插件目录（相对于仓库根目录）：

```text
prototype/dist/extension
```

1. 在 Chrome 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择上面的 `extension` 目录。
3. 点击 Chrome 工具栏里的拾词图标，打开单词本。
4. 在网页里选中英文单词或短语，右键「加入拾词单词本」，继续阅读。

快捷键默认是 macOS 的 Command + Shift + S，其他平台为 Ctrl + Shift + S。如有冲突，可在 `chrome://extensions/shortcuts` 修改。插件更新后，在扩展管理页面点击「重新加载」，再刷新已打开的单词本页面。继续使用同一目录即可保留当前扩展 ID 和单词本。

如果遇到「无法加载背景脚本」，请确认选的是 **`prototype/dist/extension`**；`prototype/extension` 是源码目录，不能直接加载。

### 从 0.1.0 更新到 0.1.1

本次修复词典 502 / 连接超时后只能等待同一服务恢复的问题。重新加载扩展后，主词典失败会自动尝试 Wiktionary。Chrome 如提示新增网站访问权限，仅用于请求 `en.wiktionary.org` 上的词典释义。

对之前已经失败的词条，点击「重试查询」即可。无需卸载插件，也无需重新收藏；自动重试已用完的词条不会自行恢复排队。

源码更新后重新构建：

```sh
npm ci
npm run build:extension
```

## 这一版已经实现

- 原生右键菜单、快捷键收词；只在主动收词时读取当前页选区及附近句子。
- 单词、原句、来源、复习标记和查询任务写入 IndexedDB，刷新或重启后保留。
- 先保存，再后台查询 Free Dictionary API；遇到 502、超时或无效响应，自动切换到 Wiktionary。
- 多个词典义项、词性、可用音标和例句都来自实际接口；Wiktionary 的备用接口不提供音标，不填入推测内容。
- 字典来源链接和对应的 CC BY-SA 许可元数据与结果一同保存和导出。
- 未收录单独标记「待确认」；网络失败保留原词、自动退避重试，最多 4 次，之后可手动重试。
- 后台任务通过持久化租约恢复，旧请求不能覆盖较新的重试结果；后台休眠后由启动事件或每分钟 alarm 继续处理。
- 重复收藏合并词条，累计次数，保留最近 50 次阅读片段。
- 搜索、筛选、重点收藏、掌握标记、按来源查看、原句翻卡复习与 JSON 导出。
- 支持手动添加词和原句，供无法读取选区的页面使用。

## 词典与模型

主词典为 [Free Dictionary API](https://dictionaryapi.dev/)，提供**英英释义**。主词典遇到网络错误、502 等服务错误、超时或无效响应时，自动尝试 [Wiktionary 释义接口](https://www.mediawiki.org/wiki/Wikimedia_REST_API)。单次主请求最多等待 10 秒，备用请求最多等待 12 秒，之后交由持久化队列退避重试。

主词典返回明确的 404 时标记「待确认」。如果主词典请求失败，而备用词典未收录或也不可用，保留为可重试的失败状态，不把服务故障误判为词典未收录。两个词典都不保证收录专业术语、缩写或新短语。

所有词典义项都会展示，当前**不自动判定哪个义项对应原句**。缩写与词典返回的普通词形不一致时会提示确认，并不自动加入复习。

模型按本轮决定暂不接入。因此没有 AI 编造的中文讲解或学习例句，也没有 API 密钥或常驻后台服务。

只把选中的词发送给词典，原句和来源 URL 保留在本机，查词请求不携带 Cookie 或页面 Referer。结果标明实际返回释义的来源，不混合两个来源的义项。Free Dictionary API 返回的许可会随词条保留；Wiktionary 结果保留原始词条链接和 [CC BY-SA 4.0](https://en.wiktionary.org/wiki/Wiktionary:Copyrights) 许可。备用接口不提供解析后的词头，缩写结果保守地标记为待确认候选。

## 网页与 PDF 的边界

| 场景 | 本版行为 |
| --- | --- |
| 普通网页文章 | 原生右键 / 快捷键收词，尽量提取完整句子及标题、URL |
| Chrome 内置文字 PDF | 优先用右键菜单的选中文本收词；不能注入脚本时仍保存词，但不虚构原句 |
| 本地 PDF | 如需文件访问，在扩展详情中开启「允许访问文件网址」；页码仅在 URL 中能读取时保留 |
| 跨域嵌入页或受限页面 | 原句提取可能失败；右键选中文本或手动添加作为降级方式 |
| 扫描版 PDF | 没有可选文字时需手动添加；本版未实现 OCR |

原生 Chrome PDF 的实际兼容性还需要在用户安装后测试；已通过的是选择文本降级逻辑的自动测试，不能据此声称所有 PDF 阅读器都兼容。

## 本地网页版

```sh
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

开发预览地址为 `http://127.0.0.1:4173/`。开发服务器为浏览器调试提供固定目标的词典同源代理；插件本身直接请求词典，不依赖这个开发代理。

网页版与插件属于不同来源，使用**各自独立的单词本**。网页版里的测试收藏不会自动出现在插件中。

卸载插件、移除解压目录后重新安装为不同扩展 ID，或清除站点数据可能使本地记录不可用。建议从「使用说明」中定期导出 JSON。当前支持导出，暂未提供导入和云同步。
